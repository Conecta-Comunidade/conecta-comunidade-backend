# ConectaComunidade Backend

## Sobre

O **ConectaComunidade** é uma API REST desenvolvida para conectar pessoas que precisam de serviços comunitários a pessoas que oferecem serviços gratuitos, permitindo a divulgação de serviços e a inscrição de beneficiários.

### Primeira Entrega

Nesta primeira entrega do **ConectaComunidade**, foram desenvolvidas as principais funcionalidades do backend, incluindo:

* **Autenticação**
* **Cadastro e consulta de usuários**
* **Criação e listagem de serviços**
* **Inscrição em serviços**
* **Cancelamento de inscrições**
* **Gerenciamento de vagas**
* **Conclusão de serviços**
* **Validação de dados e regras de negócio**

A API utiliza Java, Spring Boot, Spring Security, JWT, Docker e PostgreSQL para implementar as funcionalidades e armazenar os dados da aplicação.

A documentação dos endpoints pode ser acessada pelo Swagger após executar o projeto:

`http://localhost:8080/swagger-ui.html`

Nesta etapa, o foco foi desenvolver as principais regras de negócio e a estrutura da API para integração com o frontend.
